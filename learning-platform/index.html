🔍

Design Patterns Used

  • Factory Pattern — _build_llm_client() returns either ClaudeClient or OpenAIClient based on env config.
  • Abstract Base Class — BaseLLMClient(ABC) defines the interface both providers must implement.
  • State Machine — LangGraph StateGraph with short-circuit error propagation.
  • Repository Pattern — DatabaseService wraps all MongoDB calls.
  • DTO — PRDiff dataclass carries GitHub data between services.
💡 Key insight: The LangGraph agent and ReviewService both implement the same pipeline. LangGraph makes it composable — you can add a "security scanner" node without touching the existing code.

FastAPI — The Modern Python Web Framework

FastAPI is the foundation of every project you built. Understanding it deeply means you can explain exactly how your APIs work, why they are fast, and how they auto-generate documentation.

📚

What is FastAPI? (And why not Flask/Django?)

FastAPI is an ASGI (Asynchronous Server Gateway Interface) web framework. ASGI is the modern successor to WSGI.

FeatureWSGI (Flask, Django)ASGI (FastAPI)
Concurrency modelOne request at a time per workerThousands of concurrent requests, single thread
async/awaitNot nativeFirst-class citizen
Type hintsOptional, no integrationCore feature — drives validation + docs
Auto-docsManual or with extensionsBuilt-in /docs (Swagger) + /redoc
Performance~1000-3000 req/s~30,000+ req/s
🧠 Mental Model

Think of WSGI like a bank with one teller per queue. Each customer waits in line. ASGI is like a bank with a digital queuing system — the teller can call the next customer while the previous one is waiting for their form to be processed. FastAPI is that modern bank.

demo1_lead_classifier/app.py — App creation + middleware
from fastapi import FastAPI, HTTPException
from fastapi.middleware.cors import CORSMiddleware

app = FastAPI(
    title="KeaBuilder Lead Classifier",
    description="AI-powered lead qualification using Claude.",
    version="1.1.0",
    docs_url="/docs",
    redoc_url="/redoc"
)

app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],
    allow_methods=["*"],
    allow_headers=["*"],
)

APIRouter — Organizing Routes

When you have many endpoints, split them into routers. Your Code Review Agent uses app/api/routes/review.py and app/api/routes/webhook.py.

APIRouter pattern
# app/api/routes/review.py
from fastapi import APIRouter
router = APIRouter(prefix="/review", tags=["Reviews"])

@router.post("/")           # Actual path: POST /review/
async def trigger_review(): ...

@router.get("/{review_id}") # Actual path: GET /review/{review_id}
async def get_review(): ...

# app/main.py
from app.api.routes.review import router as review_router
app.include_router(review_router)

Pydantic v2 — Data Validation & Settings

Pydantic is the data layer of every FastAPI project. It validates inputs, serializes outputs, and loads environment variables.

app/models/review.py — your actual Pydantic models
from datetime import datetime
from enum import Enum
from typing import Optional
from pydantic import BaseModel, Field

class Verdict(str, Enum):
    APPROVE = "APPROVE"
    REQUEST_CHANGES = "REQUEST_CHANGES"
    COMMENT = "COMMENT"

class Scores(BaseModel):
    quality: int = Field(..., ge=1, le=10)    # required, min=1, max=10
    security: int = Field(..., ge=1, le=10)
    performance: int = Field(..., ge=1, le=10)

class FindingItem(BaseModel):
    file: Optional[str] = None
    line: Optional[int] = None
    description: str
    severity: Optional[str] = None

class CodeReview(BaseModel):
    repo: str
    pr_number: int
    reviewed_at: datetime = Field(default_factory=datetime.utcnow)
    bugs: list[FindingItem] = Field(default_factory=list)
    security: list[FindingItem] = Field(default_factory=list)
    scores: Scores
    final_verdict: Verdict
    summary: str
    posted_to_github: bool = False
app/config.py — BaseSettings + lru_cache singleton
from pydantic_settings import BaseSettings, SettingsConfigDict
from functools import lru_cache

class Settings(BaseSettings):
    github_token: str
    anthropic_api_key: str = ""
    llm_provider: str = "claude"
    mongodb_uri: str = "mongodb://localhost:27017"
    claude_model: str = "claude-sonnet-4-6"
    max_diff_chars: int = 50_000
    require_human_approval: bool = False

    model_config = SettingsConfigDict(
        env_file=".env",
        case_sensitive=False
    )

@lru_cache
def get_settings() -> Settings:
    return Settings()
