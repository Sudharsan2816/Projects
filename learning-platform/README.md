# Resume Project Learning Platform

An interactive, self-contained learning platform that teaches every concept, library, algorithm, and system design pattern used across all 4 resume projects.

## How to Use

Open any file directly in your browser — no server required.

| File | Content |
|------|--------|
| `index.html` | **Start here.** Home dashboard, Architecture Overview, FastAPI deep dive, Pydantic v2 |
| `part2.html` | LangGraph, Claude API + Prompt Caching, PyGithub + HMAC Webhooks, MongoDB + Motor, TF-IDF + Cosine Similarity |
| `part3.html` | pgvector + PostgreSQL Schema, sentence-transformers + FAISS, RAG Pipeline, System Design Patterns, Docker, Streamlit, Python Async/Await, Quiz Arena (10 Qs) |

## Projects Covered

1. **AI Code Review Agent** — FastAPI + LangGraph + Claude API + PyGithub + MongoDB
2. **KeaBuilder AI Assessment** — Claude Streaming + Prompt Caching + TF-IDF Lead Classifier
3. **KeaBuilder ML Assessment** — TF-IDF Similarity Search + PostgreSQL + pgvector Schema
4. **AI Market Research Copilot** — RAG + FAISS + sentence-transformers + Streamlit + Docker

## Topics Covered (16 total)

- FastAPI (ASGI, routing, async, middleware, Pydantic integration, APIRouter, Uvicorn)
- Pydantic v2 (BaseModel, Field, Enum, BaseSettings, validators, lru_cache)
- Anthropic Claude SDK (Messages API, prompt caching, streaming, async)
- LangGraph (StateGraph, TypedDict, Annotated reducers, nodes, edges, compile, ainvoke)
- PyGithub (authentication, PR diff, post comments, HMAC webhook verification)
- MongoDB + Motor (async CRUD, ObjectId, pagination)
- TF-IDF + Cosine Similarity (math, ngrams, stop_words, sparse matrices, score thresholds)
- PostgreSQL + pgvector (UUID PKs, vector type, distance operators, IVFFlat/HNSW indexes)
- sentence-transformers + FAISS (all-MiniLM-L6-v2, normalize, IndexFlatIP, search)
- RAG Pipeline (parse, chunk, embed, index, retrieve, generate)
- System Design (Strategy/Factory/ABC patterns, 3-layer fallback, Redis cache, job queues)
- Docker (Dockerfile, docker-compose, volumes, inter-container networking)
- Streamlit (session_state, multi-page, file_uploader, tabs)
- Python Async/Await (event loop, asyncio.gather, blocking vs non-blocking)
